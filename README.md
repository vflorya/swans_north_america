# Анализ пространственно-временной динамики ареала лебедей в Северной Америке

## Задачи проекта
- Загрузить и очистить данные о наблюдениях за лебедями.
- Добавить внешние данные (плотность населения и температура по штатам и провинциям).
- Провести кластерный анализ для выделения географических зон.
- Учесть сезонность и другие искажающие факторы.
- Провести статистический анализ: оценить тренды, сравнить виды и сезоны.
- Построить визуализации (не менее 4 графиков).
- Сформулировать выводы.

## Цель проекта
- Определить, наблюдается ли статистически значимое смещение ареала лебедей в Северной Америке, и выявить, различается ли это смещение в разных географических зонах. Оценить влияние внешних факторов (температура, плотность населения) на пространственное распределение птиц показать, где регистрировали лебедей разных видов;
- изучить изменение широты регистраций во времени;
- сравнить виды, сезоны и пространственные кластеры;
- оценить связь широты регистраций с годом, температурой и плотностью населения.
